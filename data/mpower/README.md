# Local MATPOWER-Compatible Test Cases

This directory is used for **locally downloaded** MATPOWER-compatible test cases.

## Important
- This directory is **not populated by default**.
- Files placed here are **not part of the repository distribution**.
- Contents are expected to be excluded from version control (e.g. via `.gitignore`).
- Two tracked exceptions, both self-built with no external license:
  `warmup_casePST.m`, a PST example case (busbar link, Harry Potter bus
  names) used as a small demo and test network, and `sp_case118.m`, a
  synthetic 118-bus case with the cardinalities of the IEEE 118-bus system
  (118 buses, 186 branches, 54 generators, 99 loads, three areas, an 11-bus
  345 kV backbone) but its own topology, parameters and names. It is
  generated by `tools/gen_sp_case118.py` (seed 118, validated there with a
  Newton-Raphson power flow, Q-limit enforcement, island check and N-1
  sweep) and stands in for the downloaded `case118.m` in the APSLF and
  scenarios workshops and their tests, so a fresh checkout runs them.
- Three more self-built cases from `tools/gen_sp_cases.py`, same premise:
  `sp_case9.m` (nine buses in the shape of the classic three-machine
  system, two transformers on off-nominal taps; its header carries the DC
  power-flow reference the generator computed with its own DC solver, the
  anchor of `test_dc_powerflow.jl`), `sp_case300.m` (300-bus operated grid,
  411 branches, the screening acceptance case) and `sp_case1354.m`
  (1354-bus grid, 2040 branches, the size probe for FD coloring, N-1
  batches and timings). They replace the cache-only case9, case14, case300
  and case1354pegase legs.

## Usage
Test cases may be downloaded automatically by example scripts or helper
functions (e.g. `FetchMatpowerCase.ensure_matpower_case`) when required.

Typical contents:

    data/mpower/
        ├─ case14.m
        ├─ case14.jl
        ├─ case118.m
        └─ ...

Both original files and locally generated derivatives (e.g. `.jl` conversions)
are considered **local artifacts**.
