# Local DTF/FOR001/FOR002 validation data

External FOR001/FOR002 validation datasets are not shipped with Sparlectra.jl.
Place local `FOR001*.DAT` and `FOR002*.DAT` files in this directory, or set
`SPARLECTRA_DTF_DIR` to the directory that holds them, when you need to run
the optional DTF/FOR002 validation scripts and tests. The repository ignores
those data files so they are not committed accidentally.
